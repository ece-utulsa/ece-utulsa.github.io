Inverting Amplifier

Linear · Amplifier

Amplifies and inverts an input signal by a precise, resistor-set ratio — the foundational building block of analog signal conditioning.

How It Works

The inverting amplifier connects the input signal through resistor Rin to the op-amp's inverting (−) input. The feedback resistor Rf runs from the output back to that same node. The non-inverting (+) input is tied to ground.

Because the op-amp has enormous open-loop gain (typically 100,000×), negative feedback forces the inverting input to sit at exactly 0 V — a condition called virtual ground. It is at 0 V without being physically connected to ground. This is the key insight that makes the circuit work.

Since the virtual ground node is at 0 V, the current through Rin is exactly Vin / Rin. Because essentially no current flows into the op-amp input itself, all of that current must flow through Rf. The output must therefore rise or fall to whatever voltage drives that current through Rf — and because the current flows in the opposite direction, the output is the inverted, scaled replica of the input.

Key Formula & Derivation

Closed-loop voltage gain Vout = −(Rf / Rin) × Vin Virtual ground: V⁻ = 0 V Current through Rin: I = Vin / Rin Same current through Rf (KCL at V⁻): Vout = −I × Rf Therefore: Vout / Vin = −Rf / Rin Gain magnitude set by resistor ratio alone — independent of op-amp gain
✦ The minus sign is not a problem — it is a feature. Cascading two inverting stages restores the original phase while providing precise, well-defined amplification. The gain depends only on the resistor ratio, not on the op-amp's internal gain.

Real-World Applications

🎙️
Audio Preamplifier
Amplifies microphone signals from millivolts to line level. The resistor ratio sets a fixed, noise-free gain; a variable Rin (potentiometer) becomes the volume control.
💡
Transimpedance Amplifier
Replace Rin with a photodiode. Current from the diode flows directly through Rf, converting light intensity to a proportional voltage — used in fiber optics and barcode scanners.
🔄
Signal Inverter / Phase Flip
With Rin = Rf, gain = −1×. Used in control systems to create the negative of a signal, enabling subtraction and differential error computation.
📡
DAC Output Stage
Scales and inverts a digital-to-analog converter's output current to match downstream voltage requirements, providing a low-impedance drive for the rest of the signal chain.

Non-Inverting Amplifier

Linear · Amplifier

Amplifies a signal with no phase inversion and extremely high input impedance — ideal for interfacing with high-impedance sensors and sources.

How It Works

The non-inverting amplifier connects the input directly to the op-amp's positive (+) terminal. The output is fed back through a resistor divider (Rf and R1) to the inverting (−) input, creating stable negative feedback.

The op-amp's enormous open-loop gain drives its two inputs to be virtually equal — a virtual short between + and −. Since the + terminal is at Vin, the − terminal is also forced to Vin. That − terminal is the midpoint of the R1/Rf voltage divider from output to ground, so we can write the divider equation and solve for gain.

Unlike the inverting configuration, the signal source sees the full differential input impedance of the op-amp — typically megaohms to gigaohms. This makes the non-inverting amp ideal when the source cannot drive a low impedance without its voltage sagging.

Key Formula & Derivation

Closed-loop relationship Vout = (1 + Rf / R1) × Vin Virtual short: V⁻ = Vin V⁻ = Vout × R1/(R1+Rf) (voltage divider) Setting equal: Vout/Vin = 1 + Rf/R1 Minimum gain = 1× when Rf = 0 (voltage follower) Always in-phase with input — no sign inversion
✦ Gain is always ≥ 1 and always positive. Setting Rf = 0 (short circuit) and R1 removed gives unity gain — the voltage follower configuration.
⚠ In this simulator the Rf slider minimum is 1 kΩ, so the lowest achievable gain is slightly above 1×. To demonstrate a true voltage follower (gain = 1), use Tab 3.

Real-World Applications

🌡️
Sensor Interface
Reads voltage from high-impedance sensors (thermistors, pH electrodes) without loading them, then drives a low-impedance ADC input cleanly.
🎚️
Audio Amplifier Stage
Provides fixed, in-phase gain in hearing aids and consumer audio where both gain accuracy and phase integrity across multiple stages are required.
🔋
Reference Buffer Amplifier
Scales a precision voltage reference from a low-current IC to supply multiple downstream circuits without drooping the reference.
🏥
Medical Instrumentation
First gain stage in ECG and EEG amplifiers, where source impedance from electrodes can reach hundreds of kilohms and must not be loaded.

Voltage Follower

Linear · Buffer

Transfers a voltage from a high-impedance source to a low-impedance load with exactly unity gain — pure impedance transformation with no signal change.

How It Works

The voltage follower is the simplest op-amp circuit: the output is connected directly back to the inverting (−) input, creating 100% negative feedback. The input is applied to the non-inverting (+) terminal. The result is a gain of exactly 1 with the output in phase with the input.

With full feedback, the virtual short forces Vout = Vin to very high precision — limited only by the op-amp's input offset voltage, typically under a millivolt. The output can source or sink tens of milliamps while the input draws essentially zero current.

The circuit's value is not amplification — it is impedance transformation. A signal source with megaohm output impedance appears to drive subsequent circuitry as if it had near-zero output impedance. This prevents the load from pulling down the source voltage.

Key Formula & Derivation

Closed-loop relationship Vout = Vin (gain = 1×, always) 100% feedback: V⁻ = Vout Virtual short: V⁺ = V⁻ Therefore: Vout = V⁺ = Vin Input impedance: 10 MΩ to 1 TΩ Output impedance: < 1 Ω (with feedback) Bandwidth limited by op-amp unity-gain bandwidth
✦ A voltage follower doesn't amplify — it isolates. The source sees a huge impedance (no loading); the load sees a near-zero impedance driver. Think of it as an ideal transformer with a 1:1 turns ratio.

Real-World Applications

⚡
ADC Driver
Isolates a sensor from an ADC's switched-capacitor input. Without the buffer, the ADC's charge kickback would corrupt the measurement at every sample.
📻
Sample-and-Hold Circuit
Holds a voltage on a capacitor during the 'hold' phase without the cap discharging through the source impedance between samples.
🔭
Active Oscilloscope Probe
The 10 MΩ probe-tip impedance is buffered to drive a 50 Ω coaxial cable without losing signal amplitude or loading the circuit under test.
🔌
Power Supply Regulation
Buffers a precision bandgap reference so it can deliver load current without the output drooping and corrupting the regulated voltage.

Summing Amplifier

Linear · Mixer

Combines multiple independently-weighted input voltages into a single output — the analog equivalent of addition, and the heart of every audio mixer.

How It Works

The summing amplifier extends the inverting amplifier by connecting multiple input resistors to the same virtual-ground node at the inverting (−) input. Because that node is held at exactly 0 V by feedback, each input source sees only its own input resistor — the other inputs have no effect.

Each input contributes an independent current (In = Vn/Rn) to the summing junction. The feedback resistor Rf must carry the total of all these currents, and the output swings to whatever voltage forces that balance. Inputs with smaller Rn contribute more current and therefore more weight in the output sum.

The virtual ground is what makes this work cleanly. In a passive resistor network, changing one input would affect all others through the shared node. Here, the op-amp holds the summing node at 0 V regardless, so inputs are completely isolated from each other.

Key Formula & Derivation

Closed-loop relationship Vout = −Rf × (V1/R1 + V2/R2 + V3/R3) Virtual ground: V⁻ = 0 V I1 = V1/R1, I2 = V2/R2, I3 = V3/R3 (independent) KCL at V⁻: I_total = I1 + I2 + I3 Vout = −Rf × I_total Equal weights: set R1 = R2 = R3 = Rf → Vout = −(V1+V2+V3)
✦ Individual channel gains are set by the ratio Rf/Rn. A 20 kΩ Rf with a 10 kΩ input gives ×2 weight; a 40 kΩ input gives ×0.5 weight. This is exactly how analog mixing consoles set individual fader levels.

Real-World Applications

🎛️
Audio Mixing Console
Combines microphone, instrument, and line-level channels into a stereo mix. Each fader is a variable Rin; the master fader is Rf.
📟
Binary-Weighted DAC
Input resistors scaled R, R/2, R/4, R/8 for binary bits. The output voltage is proportional to the binary word — a simple resistor-ladder DAC.
📐
DC Offset Corrector
Adds a precise DC voltage to an AC signal to shift its midpoint, commonly used to center a sensor output within an ADC's input range.
📺
Video Signal Combiner
Mixes luminance and chrominance components with calibrated amplitude ratios to produce a composite video signal from separate RGB sources.

Difference Amplifier

Linear · Subtractor

Amplifies only the voltage difference between two inputs while completely rejecting any voltage common to both — essential wherever noise and interference are present.

How It Works

The difference amplifier uses four resistors to implement analog subtraction. The non-inverting (+) input is driven through a voltage divider (R3, R4), and the inverting (−) input sees the other signal through R1 with feedback through Rf. When all resistors are equal, the output is simply V2 − V1.

The circuit's most valuable property is common-mode rejection. Any voltage that appears identically on both inputs — power-line interference, ground potential differences, electromagnetic noise — produces zero output. Only the difference between the two inputs is amplified.

Resistor matching is critical. If the four resistors are not in precise ratios, common-mode signals partially appear at the output. The ratio of differential gain to leaking common-mode gain is the CMRR (Common Mode Rejection Ratio). Precision resistor networks or laser-trimmed resistor arrays are used when high CMRR is needed.

Key Formula & Derivation

Closed-loop relationship Vout = (Rf / Rin) × (V2 − V1) V⁺ = V2 × Rf/(Rin+Rf) (voltage divider to ground) V⁻ forced to equal V⁺ by virtual short KCL at V⁻: Vout = (1+Rf/Rin)×V⁺ − (Rf/Rin)×V1 With matched pairs Rf/Rin: Vout = (Rf/Rin)(V2−V1) 1% resistors → CMRR ≈ 34 dB 0.1% resistors → CMRR ≈ 54 dB
✦ For higher CMRR than discrete resistors can provide, use an Instrumentation Amplifier (circuit 11), which achieves 80–120 dB CMRR with internal laser-trimmed resistors.

Real-World Applications

⚡
Current Sensing
Measures the tiny differential voltage across a shunt resistor in a power rail, rejecting the large common-mode voltage of the rail itself.
⚖️
Bridge Sensor Amplifier
Amplifies the microvolt-level imbalance of a Wheatstone bridge (strain gauge, load cell) while rejecting the large bridge excitation voltage common to both arms.
❤️
ECG / Biomedical Signal
Extracts millivolt cardiac signals that ride on top of hundreds of millivolts of common-mode interference from body motion and 50/60 Hz mains coupling.
🔧
Motor Drive Feedback
Measures back-EMF across motor terminals that float relative to the control circuit's ground, enabling speed and torque control.

Differentiator

Dynamic · Calculus

Produces an output proportional to the rate of change of the input — performs mathematical differentiation electronically in real time.

How It Works

The differentiator replaces the input resistor of the inverting amplifier with a capacitor C. Current through a capacitor is proportional to the rate of voltage change: I = C × dVin/dt. Because the inverting input is held at virtual ground by feedback, all of this capacitor current must flow through the feedback resistor Rf, developing an output voltage proportional to dVin/dt.

The faster the input changes, the larger the output. A steady DC input produces zero output. A ramp input produces a constant output. A sine wave at frequency f produces a cosine with amplitude scaled by 2πf × R × C — meaning gain increases linearly with frequency.

This frequency-proportional gain is both the differentiator's power and its Achilles heel: it amplifies high-frequency noise aggressively. A small resistor Rs in series with the input capacitor limits the gain plateau above the signal band, creating a practical, noise-stable differentiator.

Key Formula & Derivation

Closed-loop relationship Vout = −Rf × C × dVin/dt I_cap = C × dVin/dt (virtual ground at V⁻) All of I_cap flows through Rf (no current into op-amp) Vout = −I_cap × Rf = −RfC × dVin/dt For sinusoidal input A·sin(ωt): Vout = −RfCω × A·cos(ωt) |Gain| = ωRfC = 2πf·RfC (rises with frequency) Practical: add Rs in series with C to cap high-freq gain
✦ The 90° phase advance (cosine from sine input) is exactly what a PD controller needs. The output 'leads' the input, reacting to where the signal is going rather than where it is now.

Real-World Applications

📈
Edge / Transition Detector
Produces a sharp pulse at each rising or falling edge of a waveform. Used in digital signal conditioning and zero-crossing detection for phase-locked loops.
🚨
Rate-of-Change Alarm
Triggers a protection circuit when a process variable (temperature, pressure) is changing too fast — catching runaway conditions before they exceed safe limits.
🎛️
PD Controller (Derivative Term)
Provides the D term in a PID control loop, reacting to how quickly the error is changing and adding damping to prevent overshoot and oscillation.
📻
FM Demodulation
Recovers audio from an FM signal by differentiating the instantaneous frequency deviation back into a proportional amplitude signal.

Integrator

Dynamic · Calculus

Produces an output proportional to the running accumulated area under the input waveform — performs mathematical integration electronically in real time.

How It Works

The integrator replaces the feedback resistor of the inverting amplifier with a capacitor C. The input current (Vin/R) charges the capacitor continuously, and the output voltage is the integral of that current over time. Since Vcap = (1/C)∫I dt, the output grows as the running sum of all past input values.

A constant DC input produces a linearly ramping output — the capacitor charges at a constant rate. A square wave input produces a triangle wave. A sine wave at frequency f produces a cosine with amplitude divided by 2πf × R × C — gain falls with frequency, the exact inverse of the differentiator.

The ideal integrator has infinite DC gain (a capacitor blocks DC), which means any tiny input offset voltage or bias current will ramp the output slowly to saturation. Adding a large feedback resistor Rf in parallel with the capacitor limits DC gain and keeps the circuit stable for practical use.

Key Formula & Derivation

Closed-loop relationship Vout = −(1/RC) × ∫Vin dt Virtual ground: all Vin/R current flows into capacitor I_cap = Vin / R Vout = −(1/C)∫I_cap dt = −(1/RC)∫Vin dt For sinusoidal input A·sin(ωt): Vout = A/(ωRC) × cos(ωt) |Gain| = 1/(ωRC) (falls with frequency) Practical: add Rf ∥ C to prevent DC saturation
✦ The integrator 'remembers' its entire history — the output is the accumulated sum of all past inputs. This memory is exactly what makes it the core of analog control loops, waveform generators, and sigma-delta converters.

Real-World Applications

🎛️
PID Controller (I Term)
Accumulates the error signal over time, ensuring steady-state error is driven to zero even against constant load disturbances. Without it, most systems have a permanent offset.
🌊
Waveform Generator
A square wave through an integrator becomes a triangle wave. A triangle through another integrator approximates a sine. This is how function generators produce multiple waveforms.
📳
Piezoelectric Charge Amp
Integrates the charge output of piezoelectric sensors (accelerometers, hydrophones, pressure transducers) to recover a voltage proportional to displacement or force.
🔢
Sigma-Delta ADC Core
The integrator is the heart of noise-shaping modulators in high-resolution ADCs, pushing quantization noise to high frequencies where it can be digitally filtered away.

Comparator

Nonlinear · Decision

Makes a binary decision: output swings to its supply rail depending on which input is larger — the fundamental bridge between the analog and digital worlds.

How It Works

The comparator operates the op-amp fully open-loop — with no feedback at all. With open-loop gain of 100,000× or more, even a difference of a single microvolt between the inputs drives the output all the way to one supply rail. The output is therefore a two-state logic signal: high or low.

When Vin exceeds Vref, the output goes high (near V+). When Vin falls below Vref, the output goes low (near V−). The transition is nearly instantaneous and the output swings rail-to-rail, making it directly compatible with digital logic circuits.

A practical limitation appears near the threshold: small noise fluctuations cause rapid back-and-forth switching called chatter. Adding a small amount of positive feedback (hysteresis) prevents this by creating two distinct thresholds — one for rising, one for falling input. This is the Schmitt trigger, shown in circuit 9.

Key Formula & Derivation

Closed-loop relationship Vout = V+ if Vin > Vref, V− if Vin < Vref Open-loop gain A_OL ≈ 100,000× (no feedback) Vout = A_OL × (V⁺ − V⁻) Vin > Vref by even 1 µV → Vout → +rail Vin < Vref by even 1 µV → Vout → −rail Output is a digital logic level, not a linear voltage Note: dedicated comparator ICs are faster than op-amps
✦ Use a dedicated comparator IC (LM393, LM339) rather than a general-purpose op-amp for high-speed switching. Op-amps are not designed for open-loop operation and can be slow to recover from saturation.

Real-World Applications

⚡
Over/Under Voltage Detector
Monitors a supply rail and instantly triggers a protection circuit the moment voltage leaves its safe operating window — protecting sensitive downstream circuits.
〰️
Zero-Crossing Detector
Generates a clean digital pulse at every zero crossing of an AC waveform, providing a frequency reference for PLLs, motor controllers, and power factor correction.
🌡️
Window Comparator
Two comparators with upper and lower thresholds create a 'window' — output goes high only when the input is within the acceptable range, used in go/no-go testing.
🔊
PWM Generation
Comparing a DC control signal against a triangle wave reference generates a pulse-width modulated output whose duty cycle encodes the control signal's value.

Schmitt Trigger

Nonlinear · Hysteresis

A comparator with built-in hysteresis — two distinct switching thresholds eliminate chatter on noisy signals and produce clean, bounce-free digital outputs.

How It Works

The Schmitt trigger adds positive feedback to a comparator by connecting a resistor from the output back to the non-inverting (+) input. When the output is high, positive feedback raises the + threshold; when the output is low, it lowers the + threshold. This creates two distinct switching points: the Upper Threshold Voltage (VUT) and the Lower Threshold Voltage (VLT).

The input must cross VUT going upward to switch the output low, and must fall below VLT going downward to switch the output high. The gap between VUT and VLT is the hysteresis window. Any noise smaller than this window is completely ignored — it cannot cause false switching.

This hysteresis produces a transfer characteristic shaped like a rectangle when you plot Vout vs. Vin — the output follows a different path upward than downward. This 'memory' of recent history is what distinguishes the Schmitt trigger from a simple comparator.

Key Formula & Derivation

Closed-loop relationship VUT = +Vcc × R1/(R1+R2) VLT = −Vee × R1/(R1+R2) Positive feedback sets thresholds based on output state: When Vout = +Vcc: V⁺ = Vcc × R1/(R1+R2) = VUT When Vout = −Vee: V⁺ = −Vee × R1/(R1+R2) = VLT Hysteresis window = VUT − VLT = (Vcc+Vee) × R1/(R1+R2) Larger R1/R2 ratio → wider hysteresis window Switching is instantaneous once threshold is crossed
✦ The hysteresis window must be wider than the peak-to-peak noise on the signal. Set R1/R2 so the window comfortably exceeds noise amplitude — but not so wide that slow signals fail to cross both thresholds.

Real-World Applications

🔘
Pushbutton Debouncer
A mechanical switch bounces 5–20 ms on contact. The hysteresis window absorbs the bounce, producing a single clean digital edge per button press.
🌡️
Thermostat Controller
Upper and lower thresholds set the temperature band. The heater turns on at VLT and off at VUT, preventing rapid cycling around a single setpoint.
📶
Signal Squarer
Converts a sine wave or any slowly changing analog signal into a clean square wave, restoring degraded digital signals for long cable runs.
🔋
Battery Low Indicator
Monitors battery voltage with hysteresis so the low-battery LED doesn't flicker as the battery hovers near the threshold during load transients.

Sallen-Key Low-Pass Filter

Dynamic · Active Filter

A second-order active low-pass filter — attenuates signals above the cutoff frequency at −40 dB/decade.

How It Works

The Sallen-Key filter achieves a 2nd-order low-pass response using only one op-amp, two resistors, and two capacitors. The op-amp is configured as a voltage follower (or low-gain non-inverting amp), and the R-C network in front of it shapes the frequency response.

A first-order RC filter rolls off at −20 dB/decade above its cutoff. The Sallen-Key doubles this to −40 dB/decade by cascading two RC stages within a single feedback loop. The interaction between the two RC networks and the op-amp's output creates a resonance-like effect that produces a sharper transition than two isolated RC stages would give.

The quality factor Q determines the shape of the response near the cutoff frequency. In this equal-R, unity-gain topology, Q is set entirely by the capacitor ratio C1/C2. The maximum achievable Q is 0.5 (equal capacitors, critically damped). A Butterworth response (Q = 0.707) requires either unequal resistors or a gain greater than unity — it is not reachable in this configuration. Adjusting the two capacitors changes both the cutoff frequency and Q simultaneously.

Key Formula & Derivation

Closed-loop relationship f₀ = 1 / (2π × R × √(C1·C2)) Q = √(C1·C2) / (C1+C2) max Q = 0.5 Transfer function (equal R, unity-gain Sallen-Key): H(s) = ω₀² / (s² + ω₀/Q × s + ω₀²) ω₀ = 1/(R√(C1·C2)), f₀ = ω₀/(2π) Equal capacitors (C1=C2=C): Q = 0.5, f₀ = 1/(2πRC) — critically damped, max Q for this topology Above f₀: |H| rolls off at −40 dB/decade (2nd order) Butterworth (Q=0.707) requires unequal R or gain > 1
✦ Two Sallen-Key stages in cascade give a 4th-order filter at −80 dB/decade. This is the standard building block for anti-aliasing filters in ADC front ends — removing signal content above the Nyquist frequency before sampling.

Real-World Applications

🎵
Audio Crossover Network
Separates audio frequencies so bass goes to woofers and treble to tweeters, with a smooth −40 dB/decade rolloff that minimizes phase distortion in the crossover band.
📡
Anti-Aliasing Filter
Placed before an ADC to attenuate signals above the Nyquist frequency. The steep 2nd-order rolloff removes aliases without requiring a sharp brick-wall filter.
💊
Biomedical Signal Processing
Removes high-frequency noise (EMG, electrode motion artifact) from ECG or EEG signals while preserving the low-frequency physiological content of interest.
🏭
Vibration Analysis
Bandlimits accelerometer signals for modal analysis, preventing high-frequency mechanical noise from masking the structural resonances under test.

Instrumentation Amplifier

Linear · Precision

A three-op-amp precision differential amplifier with extremely high CMRR, set gain, and high input impedance on both inputs — the gold standard for sensor signal conditioning.

How It Works

The instrumentation amplifier (INA) consists of three op-amps in two stages. Stage 1 uses two matched buffer op-amps (OA1 and OA2) to amplify the differential signal without loading either input. A single external resistor Rgain sets the gain of this stage. Stage 2 is a difference amplifier (OA3) that subtracts the two stage-1 outputs to extract only the differential component.

Stage 1 provides two critical advantages over a simple difference amplifier: both inputs see the full input impedance of an op-amp (gigaohms), and common-mode signals pass through both buffers with unity gain — they are perfectly cancelled in Stage 2. Only the differential signal gets amplified in Stage 1.

Because Stage 1 gain is set by a single resistor Rgain, there is no resistor matching problem. All four Stage 2 resistors are matched internally (laser-trimmed in a monolithic IC), typically achieving 80–120 dB CMRR. This makes the INA ideal for extracting microvolt signals buried in volts of common-mode noise.

Key Formula & Derivation

Closed-loop relationship Vout = (1 + 2R/Rgain) × (V2 − V1) Stage 1 differential gain: G1 = 1 + 2R/Rgain Stage 2 difference amp gain: G2 = Rf/R = 1 (unity) Overall: Vout = G1 × (V2 − V1) CMRR of Stage 1 is theoretically infinite (matched buffers) CMRR limited by Stage 2 resistor matching Monolithic INA (INA128, AD620): CMRR > 100 dB typical
✦ For a monolithic INA IC (INA128, AD620, INA333), a single external Rgain sets gain from 1× to 1000×. The resistors and op-amps are laser-trimmed on a single die, giving CMRR and noise performance impossible to match with discrete components.

Real-World Applications

❤️
ECG / EEG Acquisition
Amplifies millivolt cardiac or microvolt brain signals from electrodes, rejecting the hundreds of millivolts of 50/60 Hz common-mode interference coupled from the body.
⚖️
Precision Load Cell
Amplifies the microvolt Wheatstone bridge imbalance from a strain-gauge load cell, rejecting the bridge excitation voltage. Used in laboratory balances and industrial weighing.
🌡️
Thermocouple Amplifier
A thermocouple generates microvolts per °C riding on the ambient common-mode voltage. The INA extracts the tiny differential temperature signal from the large common-mode.
🔬
Scientific Instrumentation
Lock-in amplifiers, precision data acquisition, and particle detector readout — any application requiring microvolt resolution in the presence of large interference voltages.

Precision Rectifier

Nonlinear · Waveform

Rectifies AC signals accurately down to millivolts by using op-amp feedback to compensate for the diode's 0.7 V forward voltage drop.

How It Works

A conventional diode rectifier loses the first 0.7 V of every half-cycle to the diode's forward voltage drop. For signals smaller than a few volts this is a significant error; for signals below 0.7 V, the diode blocks everything and rectification fails entirely.

The precision rectifier places the diode inside the op-amp's feedback loop. When the input goes positive, the op-amp drives its output high enough to forward-bias the diode and pass current — the op-amp compensates for the diode drop automatically. The output follows |Vin| accurately down to millivolts, limited only by the op-amp's offset voltage.

The half-wave version uses one diode in the feedback loop. A full-wave version (absolute value circuit) adds a second path for negative half-cycles, producing a complete |Vin| output with no dead zone. Bandwidth is limited because the op-amp must slew from saturation each half-cycle.

Key Formula & Derivation

Closed-loop relationship Vout = |Vin| (no diode drop error) Passive diode: Vout = Vin − 0.7V (0.7V dead zone) With feedback: op-amp output = Vin + 0.7V Diode drop cancels: Vout = (Vin + 0.7V) − 0.7V = Vin Effective forward voltage = Vf / A_OL ≈ 7 µV (A_OL=100k) Limited by op-amp slew rate and recovery from saturation Full-wave: use two diodes + summing stage for |Vin|
✦ Bandwidth is the main limitation — when the input crosses zero, the op-amp was saturated and must slew back. Use a fast op-amp (LF356, AD711) for signals above a few hundred hertz, or a dedicated precision rectifier IC.

Real-World Applications

📊
True RMS Measurement
The first stage of an RMS voltmeter: rectify, then square, integrate, and take the square root to get the true RMS value of any waveform shape.

Wien Bridge Oscillator

Nonlinear · Oscillator

Generates a sine wave from DC power alone — positive feedback at exactly one frequency causes sustained oscillation, while a gain of precisely 3× keeps the amplitude stable.

How It Works

Most op-amp circuits use negative feedback to set a stable gain. The Wien Bridge oscillator deliberately uses positive feedback at one specific frequency, allowing oscillation to build and sustain. The key is the Wien network: a series RC connected to a parallel RC that together form a bandpass filter with exactly 0° phase shift at the resonant frequency f₀.

For oscillation to be sustained, the Barkhausen criterion requires two conditions: the loop gain must equal exactly 1, and the total loop phase shift must be 0° (or 360°). The Wien network provides 0° phase shift at f₀ while attenuating by 1/3. The op-amp gain (set by R₁ and R₂) must therefore be exactly 3× to restore that 1/3 attenuation and achieve loop gain = 1.

If gain > 3, oscillations grow until the op-amp clips — producing a distorted, flat-topped output. If gain < 3, oscillations die out. Amplitude stabilization solves this: a nonlinear element (lamp, diode, or AGC circuit) automatically adjusts the gain to sit at exactly 3× once the desired amplitude is reached.

Key Formula & Derivation

Oscillation frequency & gain condition f₀ = 1 / (2π × R × C) | Gain = 1 + R2/R1 = 3× Wien network transfer function (series RC + parallel RC): H(jω) = (jωRC) / (1 + 3jωRC − ω²R²C²) At ω₀ = 1/RC: H(jω₀) = 1/3 with phase = 0° Barkhausen: loop gain = Amp × H = 1 → Amp = 3 → 1 + R2/R1 = 3 → R2/R1 = 2 If Amp > 3: oscillations grow → clipping (distorted) If Amp < 3: oscillations decay → silence
✦ The Wien network passes only f₀ with 0° phase. At all other frequencies the phase is non-zero, so the Barkhausen criterion is not met and those frequencies cannot sustain oscillation. This frequency selectivity is what locks the output to a pure sine wave.

Real-World Applications

🎛️
Audio Test Oscillator
HP's first product (1939) was a Wien bridge audio oscillator. Still used for THD measurement, speaker testing, and audio frequency response characterization.
🔬
Lock-In Amplifier Reference
Provides the low-distortion sine wave reference signal in lock-in amplifiers used to detect nanowatt signals in physics and chemistry experiments.
📡
Function Generator Core
The sine wave output of benchtop function generators is often a Wien bridge oscillator followed by a buffer, before triangle and square wave shaping circuits.
🎵
Musical Tone Generation
Early analog synthesizers and electronic organs used Wien bridge oscillators to generate individual notes — one oscillator per voice or key.
