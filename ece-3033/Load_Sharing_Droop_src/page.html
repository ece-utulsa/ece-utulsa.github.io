Load Sharing and Speed Droop

ECE 3033 · Lecture 4 · v2.0.0
Model

Three 100 MW units. On each, the governor on the prime mover is set by a no-load frequency fnl (the set point) and a speed droop SD. Four poles: shaft speed in r/min = 30 × f.

G1 61.00 Hz, 3.0 %; G2 61.50 Hz, 4.0 %; G3 60.80 Hz, 2.5 %. At the base set point, ffl = fnl / (1 + SD) and sP = 100 MW / (fnl − ffl). Moving a set point slides the line parallel: its slope stays the same.

Isolated: all units run at one frequency fsys = (Σ sPk fnl,k − Pload) / Σ sPk, and Pk = sPk(fnl,k − fsys). Infinite bus: fsys = 60 Hz and P = sP(fnl − 60).

Steady state only. Above 100 MW or below 0 MW (reverse power) a warning shows; nothing trips. Numbers on screen are rounded (0.1 MW, 0.01 Hz, 0.1 MW/Hz, 0.1 %, 1 r/min); the model uses the unrounded values, so a sum of rounded numbers can differ in the last digit. Every plot has fixed axes.
