WHY PARALLEL

No single generator can carry a grid, so many share one bus

Every machine on the bus runs at the same frequency and voltage.

THE INFINITE BUS

An infinite bus holds f and V fixed, whatever one generator does

Your generator is tiny next to the grid it joins.

ECE 3033 · Generators in Parallel05

THE POWER–FREQUENCY LINE

A generator's power depends on how far f sits below its set point

The set point is the no-load frequency, fnl.

The rule

P=sP(fnl−fsys)

sP in MW/Hz. Raise the governor set point fnl and the whole line moves up.

WORKED EXAMPLE · PRESS ▶ FOR EACH STEP

Work it once: two identical generators, one 2.50 MW load

Each: fnl = 61.00 Hz, sP = 1.00 MW/Hz. Find fsys, shares, fix.

1System frequency: fsys=1.00(61.00)+1.00(61.00)−2.502.00=59.75Hz
2Each share: PG1=PG2=1.00(61.00−59.75)=1.25MW
3Back to 60.00 Hz using G2 only: G1 then carries 1.00(61.00−60.00)=1.00MW, so G2 must carry 1.50 MW: fnl,2=60.00+1.501.00=61.50Hz
✓Check: (61.00 + 61.50 − 2.50) / 2.00 = 60.00 Hz; 1.00 + 1.50 = 2.50 MW.
