Model

Two synchronous generators, G1 and G2, in parallel feed one load. The bus voltage is held: Vφ = VLL / √3 at 0° is the reference for every phasor. Each machine is EA behind RA + jXS per phase (Y).

Generator convention: Q > 0 is supplied (over-excited, lagging current). I = (P − jQ) / 3Vφ; EAk = Vφ + IAk(RAk + jXSk); δk = ∠EAk.

G1 is set by P1 and one of pf1, Q1 or |EA1|. G2 makes up the difference: P2 = PL − P1, Q2 = QL − Q1, IA2 = IL − IA1 (KCL). With |EA1| given, Q1 is taken on the stable branch, with δ1 below the pull-out angle ∠ZS1.

Steady state only. A rating or reverse power raises a warning; nothing trips. Each diagram's scale is fixed by the ratings and Vφ; it changes only when a rating or VLL changes. Currents and voltages are never drawn on one diagram.
