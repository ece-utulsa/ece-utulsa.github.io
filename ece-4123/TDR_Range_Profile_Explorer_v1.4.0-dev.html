Transform

Phasor — busiest cell

Returns within one resolution cell add as phasors (blue, tip-to-tail); the red arrow is their coherent sum. Equal phase → long sum; opposite (180°) → cancels.

Pulse out, echoes back
t = 0 ns

The instrument launches a short pulse (red) down the line; its length v/B is set by the bandwidth. Each scatterer sends back an echo of strength ρ (blue). Where echoes overlap they add as phasors. The echoes arriving back at the instrument, plotted against R = v·t/2, are the range profile below.

Range profile

Click empty space to add a scatterer · drag a marker (left–right = range, up–down = strength) · set each return's phase θ in the list · double-click a marker to remove it.

Raw magnitude of the measured frequency response |S(f)| the VNA samples across the sweep — the range profile above is its inverse transform.

Bandwidth sets resolution Δr = c/(2B) and whether two close scatterers separate. Center frequency sets the wavelength λc; moving two nearby returns by ~λc/2 swings them between reinforcing and cancelling. Phase θ on each return (set in the list) controls how neighbours combine — equal phase reinforces, opposite (180°) cancels. Points set the frequency step Δf = B/(N−1) and the unambiguous range Runamb = c(N−1)/(2B); too few points for the chosen bandwidth makes distant returns alias. Window trades a sharp peak with ringing against a rounded peak with none. Gate keeps only returns inside a chosen range, like time-gating in ADS.
