Op-Amp Circuits — Tutorial

Ideal rules, the real one-pole model, and the nine circuits in the lab

1. The op-amp and its two golden rules

An operational amplifier amplifies the difference between its inputs: Vout = AOL·(V+ − V−). Open-loop gain AOL is enormous (105–106), so with negative feedback the output only has to move a few microvolts of Vd to settle. Two rules follow for the ideal device:

  • Rule 1 — no input current. Input impedance is infinite; the resistors do all the current bookkeeping.
  • Rule 2 — Vd = 0. With negative feedback the output drives V− to equal V+. When V+ is grounded, V− sits at a virtual ground: 0 V without being wired to ground.

Everything in Sections 3–9 is derived from these two rules plus Kirchhoff's current law at the inverting node. Rule 2 holds only while the output is inside its rails: once Vout is pinned at ±Vsat the loop is open and V− is set by the passive network alone — the lab computes it that way. The comparator and Schmitt trigger (Sections 10–11) have no negative feedback, so Rule 2 never applies and the output sits at a rail.

3. Inverting amplifier

Vin drives current I = Vin/Rin into the virtual-ground node. No current can enter the op-amp, so all of it continues through Rf, forcing Vout = −I·Rf.

Vout = −(Rf / Rin)·Vin Zin = Rin noise gain = 1 + Rf/Rin

The gain is set by a resistor ratio, so it is precise and temperature-stable. Cost: the input impedance is only Rin, and the output is inverted (180° phase shift — watch the X-Y screen slope downward).

4. Non-inverting amplifier

Vin goes straight to V+. Rule 2 puts V− = Vin, and the R1–Rf divider from the output must reproduce that voltage:

Vout = (1 + Rf / R1)·Vin Zin → ∞

Same polarity, gain ≥ 1, and essentially infinite input impedance — the choice for buffering sensors and high-impedance sources.

5. Voltage follower

The non-inverting amplifier with Rf = 0 and R1 → ∞: Vout = Vin. It draws no input current yet can drive RL hard — an impedance transformer. In Real mode the follower has the widest bandwidth of any configuration (noise gain 1 → fc = GBW).

6. Summing amplifier

Several inputs feed the same virtual-ground node through their own resistors; currents add and the sum flows through Rf:

Vout = −Rf·(V1/R1 + V2/R2 + V3/R3)
Inputs are isolated from each other because the node is held at 0 V — an audio mixer, a DAC ladder, an offset adder. Each input has its own path gain −Rf/Rk; there is no single "circuit gain".

7. Difference amplifier

The inverting path amplifies V1 by −R2/R1; the non-inverting path amplifies the divided V2 by (1 + R2/R1). With R3/R4 = R1/R2 the two gains match and only the difference survives:

Vout = (R2/R1)·(V2 − V1) when R4/R3 = R2/R1
Mismatch the ratio and common-mode signal leaks through; the equation strip reports the resulting CMRR in dB.

8. Differentiator

A capacitor at the input carries I = C·dVin/dt into the virtual ground; Rf converts it to a voltage:

Vout = −RfC · dVin/dt
A triangle in gives a square out; a sine gives a cosine (90° lead) of amplitude 2πf·RfC·Vpk.

The pure differentiator's gain rises without limit with frequency, which amplifies noise and — with a real op-amp — makes the loop unstable. The small series resistor Rs caps the high-frequency gain at Rf/Rs above fz = 1/(2πRsC). Set Rs very small in Real mode and watch the edges ring.

9. Integrator

The mirror circuit: current Vin/Rin charges C, and the output voltage is the capacitor voltage (inverted):

Vout = −(1 / RinC) · ∫ Vin dt
A square in gives a triangle out; a sine gives a −cosine (90° lag) of amplitude Vpk/(2πf·RinC).

Any DC component of Vin integrates without bound, so practical integrators add a leak resistor Rf across C. It limits DC gain to −Rf/Rin and the circuit only integrates above 1/(2πRfC). Give Vin a DC offset and lower Rf to see the trade-off. In this lab the Integrator accepts periodic inputs only (sine, square, triangle); use the offset slider to add a DC component.

10. Comparator

No feedback: Vout = AOL·(Vin − Vref) saturates for any difference bigger than a few tens of microvolts. The output is a logic-like signal: +Vsat when Vin > Vref, −Vsat otherwise. In Real mode the transitions take 2Vsat/SR — about 55 µs for a 741 on ±15 V — which is why dedicated comparators exist.

11. Schmitt trigger (inverting)

Positive feedback through R1–R2 moves the reference with the output. The threshold is high while the output is high and low while the output is low:

VT± = Vref·R1/(R1+R2) ± Vsat·R2/(R1+R2) hysteresis VH = 2Vsat·R2/(R1+R2)

The X-Y screen draws the characteristic rectangle. Noise smaller than VH can no longer cause chatter at the transition — the reason every mechanical switch and slow analog sensor is followed by a Schmitt trigger.

12. Reading the instrument

  • Schematic colours show every node's instantaneous voltage: green is positive, grey is 0 V, red is negative (scale bar in the sidebar). Each resistor shades from one end's colour to the other's — that shading is the voltage drop. Note the wire at the inverting input staying grey in the inverting circuits: that is the virtual ground.
  • Current: yellow chevrons move in the direction of conventional current, faster for larger current; the tag beside each part gives its current and direction. At the inverting node of the inverting amplifier, the current arriving through Rin leaves through Rf — none enters the op-amp.
  • Pills give live node voltages; their coloured dot matches that signal's scope trace.
  • Scope is a rolling display of the last few input cycles, auto-ranged; dashed red lines are ±Vsat.
  • Transfer screen plots Vout against Vin. Linear amplifiers draw a line with slope = gain; clipping bends it flat; integrators and differentiators draw ellipses (90° phase shift); the Schmitt trigger draws its hysteresis loop.
  • Load power is PL = Vout²/RL: the peak instantaneous value and the average over the displayed window.
  • Status is evaluated over the whole displayed window: SATURATED when the output spends more than 2 % of it at the rails, CURRENT-LIMITED when the Real model's Ilim clamps, SLEW-LIMITED when its dVout/dt limit is active, otherwise LINEAR.
