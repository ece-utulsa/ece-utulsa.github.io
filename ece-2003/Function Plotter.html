Functions

Available functions
  • Basic: +, -, *, /, ^
  • Trig: sin, cos, tan, asin, acos, atan
  • Hyperbolic: sinh, cosh, tanh
  • Exponential: exp, log, ln, sqrt
  • Other: abs, ceil, floor, round
  • Constants: pi, e

Important Notes:

  • pi - Use directly (e.g., sin(pi*x))
  • e - Euler's number (e.g., e^x or exp(x))
  • ln(x) - Natural logarithm (base e)
  • log(x) - Logarithm base 10
  • log(x, base) - Logarithm with custom base

Examples:

  • sin(pi*x) - Sine with period 2
  • a*sin(2*pi*x + b) - General sine wave
  • e^(-k*x) - Exponential decay
  • ln(x) - Natural log
  • a*x^2 + b*x + c - Quadratic
  • exp(-k*x) * cos(w*x) - Damped oscillation

User Guide

Everything you need to know to get started with the Function Plotter.

🚀 Quick Start

  1. Go to the Function Plotter tab.
  2. Type a function expression (e.g. sin(x)) in the input field.
  3. Click the Plot button to graph it.
  4. Adjust parameters with the sliders that appear automatically.
  5. Use + Add Function to plot multiple functions on the same graph.

📑 Tab Overview

Function Plotter

Enter custom expressions, add parameters with auto-detected sliders, set axis ranges, and overlay multiple functions. Supports degrees/radians toggle.

Functions Explorer

Browse common function types (sine, cosine, exponential, Gaussian, etc.) with interactive parameter sliders to see how parameters change shape.

Customize Plot

Fine-tune appearance: change line colors, thickness, style, fonts, grid lines, legend placement, background, and export publication-ready images.

3D Surface Explorer

Visualize 3D surfaces like paraboloids, saddle surfaces, and Gaussians. Enter custom z = f(x, y) functions. Rotate, zoom, and pan interactively.

Data Manager

Import CSV/Excel files, select columns, preview data, and plot points with automatic best-fit lines (linear regression with R² values).

✏️ Entering Functions

Type mathematical expressions using x as the variable. Any other letters (except built-in constants and functions) are treated as adjustable parameters with auto-generated sliders.

Category Functions / Operators
Basic Math+  -  *  /  ^
Trigonometricsin, cos, tan, asin, acos, atan
Hyperbolicsinh, cosh, tanh
Exponential / Logexp, ln (base e), log (base 10), log(x, base)
Othersqrt, abs, ceil, floor, round
Constantspi, e

Examples:

  • a*sin(2*pi*x + b) — Sine wave with amplitude a and phase shift b
  • a*x^2 + b*x + c — Quadratic with adjustable coefficients
  • exp(-k*x) * cos(w*x) — Damped oscillation
  • 1/(1 + exp(-k*x)) — Sigmoid function

🔄 Degrees vs. Radians

The Angle Mode setting (in Range Settings on the Function Plotter tab) controls how trig functions interpret their input:

  • Radians (default) — A full circle is 2π ≈ 6.28. Standard in most math and engineering contexts.
  • Degrees — A full circle is 360°. Useful when working with angles in degrees.

Switching modes automatically re-plots all visible functions. Affects sin, cos, tan, and their inverses.

🎨 Customizing Plots

The Customize Plot tab lets you style your plots for presentations and reports:

  • Line Colors: Color pickers for each trace.
  • Line Thickness & Style: Solid, dashed, dotted, or dash-dot.
  • Titles & Labels: Figure title and axis labels with adjustable font sizes.
  • Grid Lines: Toggle major/minor grids; change color and thickness.
  • Legend: Show/hide and choose position.
  • Background: Change plot background color.

📂 Importing Data

  1. Go to the Data Manager tab.
  2. Drag and drop a CSV or Excel file (or click to browse).
  3. Select the X column and Y column.
  4. Click Add to Plot — data points and a best-fit line (with R²) are added.
  5. Use Export as CSV/Excel to save any dataset.

💾 Exporting Your Work

  • Copy to Clipboard — Paste plots into documents or presentations.
  • Save Image — Download as PNG, SVG, or JPEG (configurable in ⚙️ Settings).
  • Print — Browser print dialog with clean layout.

🌐 3D Surfaces

Visualize z = f(x, y) surfaces with interactive controls:

  • Rotate: Click and drag.
  • Zoom: Scroll wheel.
  • Pan: Right-click and drag.
  • Reset view: Double-click.

💡 Tips

  • Use the Load Example dropdown for quick starter functions.
  • Parameters are auto-detected: any letter that isn't x or a built-in name gets a slider.
  • Uncheck a function's checkbox to hide it without deleting it.
  • Use Y-Axis Auto-scale to let the plotter find the best vertical range, or uncheck it for manual limits.
  • Hover over any point on a 2D plot to see its exact (x, y) coordinates.
  • Multiple functions and imported datasets can be overlaid on the same plot.
